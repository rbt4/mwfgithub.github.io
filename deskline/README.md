# Deskline

A quiet, installable workday clock hosted as a static Progressive Web App.

## Live structure

- `/deskline/` — product and installation page
- `/deskline/app/` — installable application

## Private signal language

- `1` schedule
- `2` pace
- `3` timer

## Design constraints

- no account
- no analytics
- no external runtime APIs
- offline-capable after first load
- Microsoft Edge PWA installation for no-admin Windows environments
- local-only settings and progress

## Version

Deskline 9.0.0
