Privacy

Deskline does not collect or transmit personal data.

Local storage

Work hours, appearance settings, acknowledgements, hydration progress and timer state are stored locally in your browser using localStorage. They remain on the device unless you clear browser data.

Network use

After the initial website load, Deskline can operate from its offline cache. It does not call analytics, advertising, location, prayer-time, weather or account APIs. Schedule calculations run inside the app.

Notifications and badges

Browser notifications are optional. Installed-app taskbar badges use neutral numeric codes and are controlled by Microsoft Edge and Windows.

Hosting

The static files are hosted through GitHub Pages. GitHub may process ordinary web-server information according to GitHub's own policies. Deskline itself contains no tracking scripts.
